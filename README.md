# Club del Último Miércoles

Web del club de lectura que se reúne el último miércoles del mes en la Librería Celama (Madrid).

- `CLAUDE.md` — contexto permanente del proyecto (stack, principios, estructura).
- `docs/PLAN.md` — plan de desarrollo por fases.
- `docs/ASSETS.md` — guía de imágenes y recursos.
- `data/seed-lecturas.csv` — importación inicial de lecturas para la pestaña «Lecturas» de la Sheet CMS (80 filas).
- `assets-src/` — originales editables (Git LFS).
