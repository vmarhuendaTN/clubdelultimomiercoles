# Contenido subido desde GitHub

Todo lo que se sube a esta carpeta se publica en la web en unos minutos (cada push a `main`
reconstruye la web) y es **público**: el repositorio lo puede ver cualquiera.
Lo que sea solo para miembros se sube desde la web (`/admin/subir`), nunca aquí.

## Cómo subir

1. En GitHub, entra en la carpeta que toque (`documentos`, `fotos/…` o `portadas`).
2. **Add file → Upload files**, arrastra los archivos y pulsa **Commit changes**.

## Carpetas

| Carpeta             | Qué va                                                | Nombre del archivo                                        |
| ------------------- | ----------------------------------------------------- | --------------------------------------------------------- |
| `documentos/`       | PDF públicos (normas, guías de lectura…)              | `normas-del-club.pdf` → se muestra como «Normas del club» |
| `fotos/AAAA-MM-DD/` | Fotos de una sesión, en una carpeta con su fecha      | cualquiera; se renombran `01.webp`, `02.webp`…            |
| `portadas/`         | Portada propia de un libro (sustituye a la de Google) | el _slug_ del libro: `la-maldicion-de-hill-house.jpg`     |

- Nombres en minúsculas, sin tildes ni espacios, con guiones.
- Formatos: PDF (máx. 20 MB); fotos y portadas en JPG, PNG o WebP (máx. 25 MB).
- Las fotos se reducen y se convierten a WebP, y se les **quitan los datos de ubicación (GPS)**.
- Fotos con personas: solo con su permiso. Lo que pasa en el Club se queda en el Club.
